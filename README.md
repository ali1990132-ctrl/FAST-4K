# FAST 4K

تطبيق FAST 4K Player.

- رابط التحميل المباشر: https://github.com/ali1990132-ctrl/FAST-4K/raw/main/FAST_4K.apk
- التحديث الداخلي يقرأ `version.json` من هذا المستودع (الفرع main).

## طريقة نشر تحديث
1. ارفع ملف التطبيق الجديد باسم `FAST_4K.apk` بدل القديم.
2. عدّل `version.json` وارفع `versionCode` لرقم أكبر من الحالي (مثلاً 2) وغيّر `versionName`.
